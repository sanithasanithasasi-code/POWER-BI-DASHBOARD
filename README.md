# 🛍️ Super Store Sales Analysis – Power BI

## 📌 Project Overview

This project focuses on analysing Super Store sales data using Microsoft Power BI.

The main objective is to understand sales performance, profitability, customer behaviour, and product returns through interactive dashboards and data visualization.

The project provides business insights using different KPIs, charts, and interactive slicers to support better decision-making.

## 🎯 Project Objectives

- Analyse overall sales and profit performance.
- Identify top-performing products and categories.
- Understand regional sales performance.
- Analyse monthly and yearly sales trends.
- Evaluate customer purchasing behaviour.
- Analyse product returns and return status.
- Identify customer contribution to total sales.
- Create interactive dashboards for business insights.
